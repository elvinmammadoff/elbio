Getting Started

Elbio is a static HTML portfolio template. There is no build step, no package manager, and no server required to run it. Open any HTML file directly in a browser to preview it.

Opening in a browser

Double-click index.html in your file manager to open it in your default browser. All paths are relative, so navigation between pages works out of the box from the filesystem.

Local server recommended. Some browser security policies block ES module imports from file:// URLs. If animations do not load, serve the folder using a simple local server: npx serve . (requires Node.js) or the VS Code Live Server extension.

Supported browsers

Elbio targets modern evergreen browsers. All features are tested against:

Browser Minimum version
Chrome / Edge 108+
Firefox 108+
Safari 16.0+
iOS Safari 16.0+

Internet Explorer is not supported. Animations degrade gracefully under prefers-reduced-motion.

File Structure

All template files live in one flat directory — no sub-projects or monorepo structure. The annotated tree below covers every file you will interact with as a buyer.

Do not edit assets/js/motion/ or assets/css/motion.css. These files contain the GSAP animation system and are versioned independently. All customization points are in the files listed above.

Customizing Colors

All colors are defined as CSS custom properties in assets/css/variables.css. The dark mode tokens are declared on :root. Light mode overrides live under [data-theme="light"] on the <html> element.

Core background tokens

--el-bg-base #0a0a0a
--el-bg-surface #111111
--el-bg-elevated #1a1a1a
--el-bg-overlay #222222

Text tokens

--el-text-primary #f0ede8
--el-text-secondary #a8a49e
--el-text-muted #5a5754

Accent tokens

--el-accent #e8a020
--el-accent-dim #c47c10
--el-accent-bright #ffc040
--el-accent-cool #4a6cf7

Overriding the accent color

To change the brand accent across the entire template, update these three tokens in assets/css/variables.css:

/* assets/css/variables.css */ :root { --el-accent: #e8a020; /* primary accent */ --el-accent-dim: #c47c10; /* hover / dark state */ --el-accent-bright: #ffc040; /* highlight */ --el-accent-glow: rgba(232, 160, 32, 0.15); /* background tint */ }

Theme variant overrides (preview.html)

preview.html demonstrates three CSS override blocks. Each block uses a scoped class on a wrapper element to swap tokens without touching the base file:

/* Cream Minimal variant */ .theme-cream { --el-bg-base: #fafaf9; --el-bg-surface: #f2f1ef; --el-text-primary: #111111; --el-text-secondary:#555555; --el-accent: #c07820; } /* Neon Cyberpunk variant */ .theme-neon { --el-bg-base: #040408; --el-accent: #a8ff3e; --el-accent-glow: rgba(168, 255, 62, 0.12); }

Customizing Fonts

Elbio uses three typefaces loaded from external CDNs. All font references go through three CSS variables so swapping a typeface requires editing exactly two places: the <link> tag in the HTML <head> and the corresponding token in variables.css.

Token Default font Role Source
--el-ff-display Cabinet Grotesk Headings, section titles, display text, nav Fontshare CDN
--el-ff-body DM Sans Paragraphs, labels, UI text Google Fonts
--el-ff-mono JetBrains Mono Code blocks, section labels, stat numbers Google Fonts

Swapping Cabinet Grotesk

Cabinet Grotesk is loaded via Fontshare. To replace it with a Google Font (e.g., Plus Jakarta Sans):

  1. Replace the Fontshare link in every HTML file's <head>

    <!-- Remove --> <link href="https://api.fontshare.com/v2/css?f[]=cabinet-grotesk@400,500,700,800,900&display=swap" rel="stylesheet"> <!-- Add --> <link href="https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;700;800;900&display=swap" rel="stylesheet">

  2. Update the token in assets/css/variables.css

    --el-ff-display: "Plus Jakarta Sans", sans-serif;

Type scale

All heading sizes use clamp() for fluid scaling between mobile and desktop. The tokens are defined in variables.css under the TYPOGRAPHY block. --el-fz-h1 through --el-fz-h6 control the heading scale; --el-fz-display (clamp(80px, 14vw, 200px)) is the hero mega-text size.

Adding Projects

Project data lives in assets/data/projects.json. The project-single.html page reads the ?project=<slug> URL parameter and populates the case study from the matching JSON entry. The homepage grid is rendered statically in index.html — you duplicate a card block there to add a new project to the visible list.

JSON schema — every field

{ "id": 1, // integer, unique, used for prev/next navigation "slug": "lumora-saas-dashboard", // string — must match the ?project= URL param // and the image folder name "title": "Lumora — SaaS Analytics", // string — displayed in card and page <h1> "tags": ["UI Design", "SaaS"], // string[] — shown as chips; used by filter "year": "2024", // string — shown in card meta and case study "role": "Lead Product Designer", // string — shown in case study metadata row "description": "Short summary…", // string — card excerpt and hero subtitle "challenge": "Problem statement…", // string — "The Challenge" section body "solution": "How you solved it…", // string — "The Solution" section body "results": [ // string[] — bullet list in "Results" section "Metric one", "Metric two" ], "tech": ["Figma", "React"], // string[] — rendered as tech-stack badges "images": { "cover": "assets/images/projects/<slug>/cover.jpg", // 16:9 or 4:3 recommended "gallery": [ // string[] — full-width mockup grid images "assets/images/projects/<slug>/mockup-01.jpg", "assets/images/projects/<slug>/mockup-02.jpg" ] } }

Step-by-step: add a new project

  1. Create an image folder

    Add a new folder at assets/images/projects/your-project-slug/. Place your cover.jpg and any mockup-*.jpg files inside.

  2. Append an entry to projects.json

    Copy an existing entry, set a new unique id, and update all fields. The slug must exactly match the folder name and the URL parameter you will link to.

  3. Add a card to index.html

    In the #projects section, duplicate one of the existing <article class="project-card"> blocks. Update the data-tags attribute, image src, title text, description, year, and the href links to project-single.html?project=your-project-slug.

Image sizes: Cover images look best at 1200×800px minimum. Mockup/gallery images can be any aspect ratio — they are displayed at full template width with object-fit: cover. Use JPEG at 80% quality to keep file sizes reasonable.

Theme Switching

Elbio ships with dark mode as the default and includes a toggle button in every page header. The system has three components: an inline script that prevents flash-of-unstyled-content (FOUC), a CSS variable override block for light mode, and a toggle button wired up by main.js.

How theme-init.js works

assets/js/theme-init.js is loaded as the very first script in every page's <head> — before any CSS — so it runs synchronously before the browser paints. It:

  1. Reads localStorage.getItem('el-theme')

    If the user has previously toggled, the saved value is "light" or "dark".

  2. Falls back to prefers-color-scheme

    If no value is saved, the OS-level preference is respected.

  3. Sets data-theme on <html>

    The CSS selector [data-theme="light"] in variables.css overrides all background, text, and border tokens to their light-mode equivalents.

Toggle button behavior

The .theme-toggle button in the nav is handled by assets/js/main.js. On click it flips the data-theme attribute and writes the new value to localStorage. The button's aria-label is updated to reflect the current state.

Defaulting to light mode

To make light mode the default, edit the preference check in assets/js/theme-init.js:

// Change the fallback from 'dark' to 'light' var savedTheme = localStorage.getItem('el-theme') || 'light';

Web3Forms Setup

Both contact.html and the quick-contact form on index.html use Web3Forms — a free, serverless form endpoint that requires no backend. Submissions are forwarded to your email address.

  1. Sign up at web3forms.com

    Go to web3forms.com and enter your email address. Web3Forms will send you a confirmation email with your access key. No account password required.

  2. Copy your access key

    The access key is a UUID string like xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.

  3. Replace the placeholder in contact.html

    Open contact.html and find the two placeholder values. Replace both with your key:

    <form data-web3forms-key="YOUR_WEB3FORMS_ACCESS_KEY" action="https://api.web3forms.com/submit" ... > <input type="hidden" name="access_key" value="YOUR_WEB3FORMS_ACCESS_KEY">

  4. Do the same in index.html

    The quick-contact form in the #contact section of index.html has identical placeholders — replace them the same way.

  5. Customise the email subject (optional)

    The <input type="hidden" name="subject"> field controls the subject line of the notification email. Change value="New inquiry from elbio.design" to whatever you prefer.

  6. Test a submission

    Open the page in a browser (use a local server — see Getting Started), fill out the form, and submit. You should receive a confirmation email within seconds. The form will display a success message in the .form-status element.

Spam protection: Both forms include a hidden botcheck checkbox (honeypot). Bots that fill in hidden fields are silently rejected by Web3Forms. No CAPTCHA is required.

Motion System

Elbio's animation system lives entirely in assets/js/motion/ and assets/css/motion.css. You activate animations by placing data-motion and data-cursor attributes on HTML elements — no JavaScript configuration required.

Required CDN script order

These four script tags must appear in this order just before </body> in every HTML page. They are already included in all template pages.

<!-- 1. Lenis smooth scroll --> <script src="https://cdn.jsdelivr.net/npm/@studio-freight/lenis@1.0.42/dist/lenis.min.js" defer></script> <!-- 2. GSAP core --> <script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js" defer></script> <!-- 3. GSAP ScrollTrigger --> <script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/ScrollTrigger.min.js" defer></script> <!-- 4. Motion system entry point (ES module) --> <script type="module" src="assets/js/motion/index.js"></script>

data-motion attribute reference

Attribute value Effect Apply to
word-mask Hero word-mask reveal — words slide up from clipped baseline Hero heading container. Each word needs <span class="word-wrap"><span class="word">…</span></span>
reveal Single element fade-up on scroll enter (y: 40→0) Any single content element
reveal-stagger Stagger reveal across direct children (same as reveal, stagger 0.12) Card grids, list wrappers
reveal-clip Clip-path wipe in from bottom (inset(100%→0%)) Images, full-width media
line-reveal Paragraph lines rotate in from rotationX: -80 Hero description paragraph
clip-circle Portrait reveal — circle(0%→55%) clip-path expand Hero portrait image wrapper
rule-wipe Horizontal rule wipes in from center (scaleX: 0→1) <hr> or .rule dividers in hero
counter Animated number count-up on scroll enter <span> wrapping a numeric value
scramble Random character scramble resolves on hover Nav link spans, CTA labels
magnetic Button follows cursor proximity Primary CTA buttons
tilt Real-time 3D mouse-tracked tilt (±10°) Portfolio cards, blog cards
parallax Scroll-linked vertical offset Background images, decorative elements
marquee Infinite horizontal ticker (pauses on hover) Skills / clients track container
pin-stack Sequential card stacking with scale 0.78 Portfolio stack section wrapper

data-cursor attribute reference

The magic cursor uses a single attribute. Whatever you put as the value becomes the label rendered inside the expanded ring. HTML is allowed in the value (use <br> for two-line labels). The ring expands to ~96×96 px on hover; otherwise it sits at 14 px with mix-blend-mode: difference so it stays visible on every background.

Attribute value Behaviour Typical target
data-cursor="link" Expands the ring with no label inside. Links, nav items, CTA buttons, theme toggle, menu toggle.
data-cursor="View" Expands the ring and renders "View" inside. Portfolio cards, project covers, blog cards.
data-cursor="View<br>Demo" Two-line label inside the ring (HTML allowed in the value). Preview / demo grid cards.
data-cursor="Drag" · data-cursor="Read" · any text The value is the label — set whatever fits the affordance. Carousel slides ("Drag"), article cards ("Read"), image lightboxes ("Open").
Reduced motion: All GSAP animations are guarded by prefers-reduced-motion: reduce. When the user has reduced motion enabled in their OS, all animations are skipped and elements are shown at their final state immediately. The custom cursor is hidden on touch devices (pointer: coarse).
